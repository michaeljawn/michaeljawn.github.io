Project Overview

  • Designed and implemented a relational database system to analyze fantasy football performance using real-world player statistics.
  • Engineered a normalized schema with interconnected tables using primary and foreign key relationships.
  • Developed advanced SQL queries utilizing joins, aggregations, and window functions to generate weekly rankings, positional leaderboards, and player performance metrics.
  • Implemented analytical queries to detect breakout performances, calculate fantasy points per game, and evaluate player consistency using statistical functions.
  • Created database views to streamline common analytical queries and support scalable data exploration.
  • Structured the project using modular SQL scripts and documentation to support reproducibility and a professional GitHub presentation.
