Project Overview

  • Developed a fully functional Connect 4 game for Android, implementing an interactive UI using XML-based layout and Android widgets.
  • Engineered three AI difficulty levels (Easy, Medium, Hard) using algorithmic decision-making to simulate real gameplay.
  • Applied object-oriented programming prinicples to structure game logic and maintainability.
  • Utilized an Android Activity lifecycle and event listeners for seamless user interaction.
  • Designed and tested game mechanics to ensure a smooth and responsive player experience.
  • Managed project development in an Agile-style workflow, iterating on UI and gameplay improvements based on testing feedback.
